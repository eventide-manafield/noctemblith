# Manafield 적용 환경의 로컬 관리자 로그인

## 접속 경로

마나필드 적용 인스턴스의 로컬 관리자 로그인 주소는 다음과 같습니다.

`https://<서버 호스트>/auth/local-admin`

관리자는 이 주소를 직접 입력하거나 즐겨찾기로 보관해 주세요. 공개 로그인 화면, 사이트 푸터와 일반 메뉴에는 관리자 로그인 링크를 표시하지 않습니다. 일반 사용자는 마나필드 계정으로 로그인합니다.

## 대상 계정

- 해당 서버에서 관리자 권한을 가진 활성 로컬 계정(root 포함)만 이용할 수 있습니다.
- 마나필드 중앙 계정과 연결된 계정은 이 경로의 대상이 아닙니다.
- 모더레이터 권한만 가진 계정, 정지·삭제된 계정과 원격 계정은 이용할 수 없습니다.
- 서버에서 현재 권한과 연결 상태를 다시 확인합니다. URL을 아는 것만으로 접근 권한이 생기지 않습니다.

## 인증과 로그아웃

기존 비밀번호·패스키와 설정된 다중 인증 절차를 그대로 사용합니다. 비밀번호 재설정이나 MFA 해제를 이 경로에서 자동 수행하지 않습니다.

로그인하면 계정 공용 native 토큰 대신 개별 로컬 관리자 브라우저 세션(`nla1_`)이 발급됩니다. 토큰은 Redis에 원문으로 저장하지 않으며 상한 수명은 기존 통합 브라우저 세션과 같은 30일입니다. 녹템블리스 로그아웃은 서버의 해당 세션을 철회합니다.

이 관리용 세션은 중앙 부모가 없는 로컬 예외이며 마나필드 로그인 세션을 생성하지 않습니다. 중앙 서비스에 장애가 있어도 로컬 DB·Redis가 정상이고 관리자 자격이 유효하면 이용할 수 있습니다. 관리자 권한 상실·계정 정지/삭제·중앙 계정 연결 이후에는 인증을 허용하지 않습니다. 기존 계정 토큰 재발급도 모든 로컬 관리자 세션을 무효화합니다. 세션에는 원문 계정 토큰 대신 단방향 자격증명 버전 해시만 보관합니다.

## 독립 설치

마나필드 모듈이 없는 녹템블리스는 기존 자체 로그인·패스키·MFA를 그대로 사용합니다. 위 통합 전용 관리자 API는 활성화되지 않습니다.

## 현재 구현 범위

이 문서는 0.1.1 릴리스 소스의 동작을 설명합니다. 실서버 배포 완료를 뜻하지 않습니다. 중앙 계정과 연결된 관리자/모더레이터의 SSO 추가 MFA는 별도 미완성 과제이며, 해당 계정에 이 로컬 예외를 적용하여 우회하지 않습니다.


일반 사용자의 미연동 기존 계정은 로컬 로그인으로 우회할 수 없습니다. 동일 핸들의 기존 계정이 있으면 소유권 확인과 중앙 계정 연결을 관리자에게 문의하도록 안내합니다. 핸들이 같다는 이유만으로 기존 계정의 소유권을 자동 이전하지 않습니다. 별도의 관리자 보조 계정 연결 절차는 이 변경에 포함되지 않습니다.
