# 녹템블리스 문서

**한국어 문서를 기준 문서로 우선합니다.** 한국어판을 먼저 검토·수정한 뒤, 그 내용을 기준으로 영문을 갱신합니다.

## 현재 상태부터 확인하기

- [현재 배포·검증 현황](ko/deployment-status.md) — 실제 실행 커밋, 리소스 구성, 로그인·세션, 사용자 검증, 미완료 작업을 기록합니다.

현재 문서화의 첫 단계는 과거 영문을 그대로 번역하는 것이 아니라, 실제 배포 상태를 한국어로 기록하는 작업입니다. 아직 아래 문서 전체를 현재 상태로 개정하거나 한국어로 번역한 것은 아닙니다.

## 기존 문서

아래 문서는 보존된 설계·구현 단계의 참고 자료입니다. 이미 한국어로 작성된 자료도 포함합니다. 문서 안의 구현·배포 상태와 검증 명령이 현재 릴리스와 다를 수 있습니다. 최신 운영 상태를 판단할 때는 위 현황 문서를 우선 확인해 주세요.

## 문서 작업 순서

1. 실제 코드와 배포 증거를 확인해 한국어 현황을 작성합니다.
2. 사용자가 한국어 문서의 표현·구성·방향을 수정합니다.
3. 확정된 한국어 내용에 맞추어 관련 주제 문서를 정리하고 영문에 반영합니다.
4. 코드 식별자, API 경로, 환경변수, 검증된 명령은 설명과 구분하여 유지합니다.
